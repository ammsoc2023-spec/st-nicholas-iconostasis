Iconostasis – St Nicholas Bankstown – offline PWA (EN / МК)
Static files only; served from GitHub Pages. Open once on the phone (everything is cached), then:
 iPhone (Safari): Share → Add to Home Screen.   Android (Chrome): menu ⋮ → Install app.
Data: data.js (20 booklet pages transcribed verbatim from the booklet video, 25 hotspots in % of the photo).
Images: img/iconostasis.jpg, img/church/*.jpg (crops of the photo), img/booklet/pNN.jpg (booklet icon pictures).
Build sources: /workspace/iconostasis/ . If files change, regenerate sw.js so the cache name changes.
